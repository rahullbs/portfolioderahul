# Your Personal Website

Generated by [Rezoomed](https://rezoomed.com) — deploy it anywhere in minutes.

## Deploy to Vercel (recommended, free)

1. Create a free account at [vercel.com](https://vercel.com)
2. Install Vercel CLI: `npm i -g vercel`
3. In this folder, run: `vercel`
4. Follow the prompts — your site will be live in ~30 seconds

## Deploy to Netlify (free)

1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop this entire folder onto the page
3. Your site is live instantly

## Deploy to GitHub Pages (free)

1. Create a new GitHub repository
2. Push all files in this folder to the repo
3. Go to Settings → Pages → select "Deploy from a branch" → main / root
4. GitHub will publish your site at `https://yourusername.github.io/repo-name`

## Notes

- **Images**: loaded from their original URLs — requires an internet connection
- **Fonts**: served from Google Fonts CDN — requires an internet connection
- **Custom domain**: all platforms above support custom domains for free
